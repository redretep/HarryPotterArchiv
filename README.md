# Harry Potter Archiv ⚡️
<img width="1918" height="922" alt="image" src="https://github.com/user-attachments/assets/e5d0e385-6778-4a8a-b073-b26151de9f72" />

das ist dein archiv für alle sieben harry potter hörbücher, gelesen von rufus beck. sieht aus wie spotify, funktioniert aber im browser.

## features

* **automatisch laden:** zieht sich alle kapitel direkt aus listen.
* **sieht gut aus:** schickes design, das auch auf dem handy klappt.
* **player-features:** sleep timer, speed changer und lautstärkeregler sind implementiert.
* **downloads:** lad dir einzelne folgen oder direkt das ganze buch als zip-datei.

---

## wie man es benutzt

öffne das [archiv](https://harrypotter.pidi.workers.dev) in einem halbwegs modernen web-browser. speichere die seite, damit du sie später wiederfindest oder füge sie zum home-bildschirm hinzu (handy).
